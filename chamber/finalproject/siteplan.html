WDD231 Individual Website Project Site Plan

1. Site Name

Maths Challenge Hub

I selected the name Maths Challenge Hub because it represents a central place where primary school learners can explore mathematics through fun challenges, puzzles, quizzes and educational resources.

The word "Maths" clearly identifies the subject, "Challenge" communicates the interactive activities learners will enjoy, while "Hub" represents a central place for learning and discovering mathematical ideas.

Proposed domain: maths-challenge-hub.com

Tagline: Think • Solve • Learn • Enjoy!

2. Site Purpose

Maths Challenge Hub is an educational website designed to help primary school learners improve their mathematical skills through enjoyable and interactive learning experiences.

The website will provide mathematical challenges, brain teasers, quizzes, puzzles and learning resources that encourage learners to develop critical thinking, logical reasoning and problem-solving skills.

It will also provide a welcoming learning environment where children can practise mathematical concepts, test their knowledge and build confidence in mathematics.

Main Website Content

  • Interactive mathematics challenges and quizzes.
  • Mathematical puzzles and brain teasers.
  • Learning tips and explanations of mathematical concepts.
  • Practice questions covering different areas of mathematics.
  • Feedback to help learners check their answers.

3. Target Audience

The main target audience is primary school learners, particularly children between the ages of 8 and 12. Teachers and parents may also use the website to support children's mathematics education.

The website will use simple language, colourful presentation, clear instructions and age-appropriate activities to make mathematics accessible and enjoyable.

4. Scenarios

The following questions represent what visitors to Maths Challenge Hub may want to know or accomplish.

Scenario 1

How can I practise multiplication and division through fun mathematics challenges?

Scenario 2

Where can I find interesting mathematical puzzles that will improve my problem-solving skills?

Scenario 3

How can I check my answers and know whether I have solved a mathematics question correctly?

Scenario 4

Where can I find simple explanations and helpful tips for understanding difficult mathematical topics?

6. Typography

Two fonts will be used throughout the website to maintain readability and a consistent visual identity.

Font 1: Nunito

Maths Challenge Hub

This font will be used for the main title, section headings, subheadings and important labels. Its friendly appearance makes the website welcoming to young learners.

Font 2: Open Sans

Mathematics becomes enjoyable when learners practise regularly, explore new challenges and discover solutions.

This font will be used for paragraphs, instructions, navigation links and general website content because it is clear and easy to read.

7. Website Structure and Navigation

The website will contain three main pages connected through a responsive navigation menu.

Page 1: Home (index.html)

  • Introduction to Maths Challenge Hub.
  • Welcome message and website purpose.
  • Featured mathematics challenges.
  • Links to the challenges and learning resources pages.

Page 2: Challenges (challenges.html)

  • Interactive mathematics questions and quizzes.
  • At least fifteen dynamically generated challenge items.
  • Different mathematical topics and difficulty levels.
  • Buttons for checking answers and viewing explanations.
  • Modal dialog for displaying additional challenge information.

Page 3: Learning Resources (resources.html)

  • Mathematical tips and learning materials.
  • Explanations of important mathematical concepts.
  • Study and practice recommendations.
  • Helpful learning links and resources.

Additional Supporting Pages

  • Attributions page for acknowledging external sources.
  • Form action page for displaying submitted form information.

8. JavaScript Functionality

JavaScript will be used to make Maths Challenge Hub interactive and dynamic.

  • Data Fetching: Fetch mathematics challenges from a local JSON file using the Fetch API and async/await.
  • Error Handling: Use try...catch blocks to handle errors during data retrieval.
  • Dynamic Content: Generate and display at least fifteen mathematics challenges from the data source, with at least four properties per item.
  • Local Storage: Save learners' preferences or challenge progress.
  • Modal Dialog: Display additional information, explanations or feedback when a learner selects a challenge.
  • DOM Manipulation: Use JavaScript to update page content and respond to user interactions.
  • Array Methods: Use methods such as forEach(), map() and filter() to process challenge data.
  • Template Literals: Generate dynamic HTML content using template literals.
  • ES Modules: Organise JavaScript into reusable modules.

10. Responsive Design and Accessibility

  • The website will adapt to mobile, tablet and desktop screens.
  • A hamburger menu will be provided for smaller screens.
  • Desktop navigation links will display horizontally.
  • Semantic HTML elements will be used throughout the website.
  • Images will include appropriate alternative text.
  • Forms and interactive elements will have accessible labels.
  • Keyboard navigation and visible focus indicators will support accessibility.
  • Images will be optimised and lazy-loaded where appropriate.

11. Testing and Evaluation

The completed site plan and website will be tested using the following tools:

  • W3C Markup Validator: To identify and correct HTML errors.
  • WAVE Accessibility Evaluation Tool: To identify accessibility issues.
  • Google PageSpeed Insights / Lighthouse: To evaluate performance, accessibility, best practices and SEO.
  • WebAIM Contrast Checker: To check colour contrast and readability.
  • Browser Testing: To check the website on different browsers and screen sizes.
